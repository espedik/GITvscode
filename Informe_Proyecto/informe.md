## Estructura General

El repositorio contiene ejercicios y proyectos de Python organizados por tema. Es un portafolio de aprendizaje que cubre desde estructuras de datos básicas hasta pruebas unitarias y proyectos aplicados a la industria aeroespacial.

---

## Módulos y Contenido

### 1. `Ejercicios_Listas` — 18 archivos
Serie progresiva de ejercicios sobre listas en Python:
- Creación, modificación, slicing y funciones básicas (archivos 1–4)
- Ordenamiento, bucles y unión de listas (5–7)
- Localizador de fallos y matrices (8–9)
- Copia, comprehension list, reversión y sincronización (10–13)
- Extracción, deep copy, limpieza de duplicados (14–16)
- Formateo de reportes y análisis de complejidad Big O (17–18)

### 2. `Ejercicios_Strings` — 12 archivos
Ejercicios sobre cadenas de texto:
- Slicing, limpieza, print, split, booleans (1–5)
- Salto de línea, bucles for, replace, find (6–9)
- Ordenamiento, reconstructor y zFill (10–12)

### 3. `Ejercicios_Diccionarios` — 0 archivos
Carpeta creada, pendiente de contenido.

### 4. `POO` — 3 archivos
Programación Orientada a Objetos:
- `calculadora.py` — Clase calculadora
- `Herencia.py` — Ejemplo de herencia
- `Libros.py` — Modelo de datos con clases

### 5. `Pytest` — 4 archivos
Pruebas unitarias con pytest:
- `calculadora/` — Módulo calculadora + tests
- `termostato/` — Módulo sensor de temperatura + tests

### 6. `Python_Guide` — 10 archivos
Scripts de referencia y ejercicios variados:
- Estructuras base: strings, listas, tuplas, diccionarios
- Problemas de algoritmos: `Alfabeto_Alienigena.py`, `SubCadena_SinRepetir.py`, `Listas_Ordenadas.py`
- Exámenes estilo Amazon: `Amazon_Examen.py`, `Amazon_Examen_Alrevez.py`

### 7. `WebScraping` — 1 archivo
- `Web.py` — Script de web scraping

### 8. `test_Honeywell` — 10 archivos
Proyecto aplicado a sistemas aeroespaciales (estilo Honeywell):
- `Auxiliary_Power_Unit/` — APU con versión con error y versión resuelta
- `Landing_Gear/` — Control de tren de aterrizaje con error y solución
- `oxigen_control/` — Control de oxígeno (3 versiones: básica, pytest, unittest)
- `temperature/` — Control de temperatura (pytest y unittest)
- `EjercicioFinal.py` — Ejercicio integrador final
